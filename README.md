## 🚀 Featured Projects

### 🧬 [OncoMark](https://github.com/iamcamellia/oncomark) — Multi-Task Neural Framework for Cancer Hallmark Classification
> PyTorch · scikit-learn · Pandas · TCGA data · Git

Built a high-throughput multi-task neural network to classify 14 cancer hallmark categories from transcriptomic and proteomic data across 10+ TCGA cancer cohorts. Full pipeline: data acquisition → preprocessing → feature engineering → model training → SHAP-based interpretation.

📄 *Published: Communications Biology, Nature Portfolio (2025)*

---

### 🏥 [Hospital-Ops-Analytics](https://github.com/iamcamellia/hospital-ops-analytics) — Clinical Operations Dashboard
> SQL · Python · Tableau · Excel

Analytics pipeline on 100,000+ simulated patient records. SQL data engineering, Python-based cohort analysis, and Tableau dashboards for operational KPI reporting. Identifies high-risk patient segments and resource utilisation patterns.

---

### 📑 [FDA-510k-Extractor](https://github.com/iamcamellia/fda-510k-extractor) — Regulatory Data Extraction Workflow
> Python · Excel · regex · openpyxl

Automated extraction of structured fields from FDA 510(k) regulatory submissions into validated, consistently formatted Excel output tables. Built to reduce manual data entry in regulatory review workflows.
